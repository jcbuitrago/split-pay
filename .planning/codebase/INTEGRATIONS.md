# External Integrations

**Analysis Date:** 2026-08-25

## APIs & External Services

**Vision/OCR:**
- Anthropic Claude Vision API (claude-haiku-4-5 model)
  - What it's used for: Extract line items, prices, and quantities from receipt images
  - SDK/Client: Native Fetch API (called via Cloudflare Worker proxy at `worker/index.js`)
  - Auth: `ANTHROPIC_API_KEY` environment secret
  - Endpoint: `https://api.anthropic.com/v1/messages`
  - Max image size: 8 MB base64 (~6 MB compressed)
  - Request timeout: 25 seconds (AbortController in `worker/index.js:78`)
  - Model: claude-haiku-4-5 (optimized for speed on vision tasks)
  - Max tokens per request: 1024

## Data Storage

**Databases:**
- Not used - Application state is ephemeral (memory-only, lost on page close)

**File Storage:**
- Local filesystem only - No cloud storage used
- Images are Base64-encoded and sent to Anthropic but not persisted
- After Step 1, `originalImage` is discarded from state (`src/context/BillContext.tsx` case `SET_STEP`)

**Caching:**
- None - Service worker (vite-plugin-pwa) caches static assets (JS, CSS, fonts) for offline PWA functionality
- No API response caching

## Authentication & Identity

**Auth Provider:**
- Custom (no external provider) - App is stateless; no user accounts or login
- Implementation: No authentication layer; bill data is client-only and not persisted

**Session Management:**
- In-memory Context API state (`src/context/BillContext.tsx`)
- No tokens, JWT, or session storage
- No login/logout flow

## Monitoring & Observability

**Error Tracking:**
- Not configured - Error messages displayed in UI but not sent to tracking service

**Logs:**
- Frontend: Browser console only (logs in development)
- Worker: Cloudflare Worker logs (visible in Wrangler dashboard and `wrangler tail` command)
  - Key logs: Anthropic API errors, rate limit violations, malformed requests

**Security Logging:**
- CORS origin validation logged at worker level (`worker/index.js:127`)

## Rate Limiting & Quotas

**Anthropic API:**
- No explicit quota configured; subject to Anthropic's pricing and rate limits
- Client-side: No rate limiting enforced

**Cloudflare Worker:**
- Rate limit: 20 requests per hour per IP address
- Implementation: In-memory Map with fallback to Cloudflare KV (if configured)
- Response: HTTP 429 if limit exceeded
- Reset window: 1 hour

## Security & CORS

**CORS Configuration (`worker/index.js`):**
- Allowed origins: Whitelist from `ALLOWED_ORIGIN` (never reflects client Origin)
- Allowed methods: `POST`, `OPTIONS`
- Allowed headers: `Content-Type`
- Preflight handling: OPTIONS requests return 204 with CORS headers

**Security Headers (`vercel.json`):**
- `Content-Security-Policy` - Restricts scripts, styles, fonts, images
- `X-Frame-Options: DENY` - Prevents clickjacking
- `X-Content-Type-Options: nosniff` - Prevents MIME type sniffing
- `Strict-Transport-Security` - Enforces HTTPS for 1 year
- `Referrer-Policy: strict-origin-when-cross-origin` - Controls referrer leakage
- `Permissions-Policy: camera=(self)` - Restricts camera access to same origin only
